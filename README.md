# Scegli la struttura dati

Autotest per il corso di Informatica (Python): dato un problema nello stile dei temi d'esame, scegliere la struttura dati più adatta, senza scrivere codice.

Ogni test ha 10 domande di difficoltà diversa, estratte da un pool di 252. I risultati restano solo nel browser di chi fa il test.

Il quiz è online su [GitHub Pages](https://alfredobenso.github.io/PythonArrangement/).
